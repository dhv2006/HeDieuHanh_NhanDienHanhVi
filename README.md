# HeDieuHanh_NhanDienHanhVi
Đồ án nhận diện hành vi thông qua video. Nhóm thành viên: Vũ Việt Hà, Trần Nam Long, Lý Thành Thông, Đoàn Đức Thịnh, Trần Thanh Tú, Lý Thành Thông
Hướng dẫn cài đặt và chạy
1. cài python 3.13.15 hoặc mới hơn
2. tải full repo trên github này về
3. giải nén ra thư mục
4. mở thư mục và chạy
## Chạy
- Windows: bấm đúp `start.bat`
- macOS / Linux: `./start.sh`
- Hoặc: `python server.py` rồi mở http://localhost:8000
Thêm:
- Link YouTube/TikTok/FB: chạy `setup_video_urls.bat` (cài yt-dlp) một lần.
- Gemini miễn phí: lấy API Key tại aistudio.google.com/apikey → dán vào tab **Hệ thống → Cài đặt AI**.
- Dùng offline: `python tools/download_offline.py`.
